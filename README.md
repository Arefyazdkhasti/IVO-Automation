# IVO Automation (سامانه یکپارچه قرنطینه و امنیت زیستی دامپزشکی)

این پروژه یک اسکریپت اتوماسیون با استفاده از **Playwright** برای ورود خودکار به سامانه دامپزشکی (`e.ivo.ir`) به ازای لیست مشخصی از کاربران، بررسی وضعیت گواهی‌های حمل صادرشده، استخراج کدهای تخلیه‌نشده و ثبت خودکار تایید تخلیه است.

---

## 📋 قابلیت‌های اصلی سیستم

1. **مدیریت چندکاربره:** خواندن لیست کاربران از فایل `users.json` و اجرای سشن‌های مجزا برای هر کاربر.
2. **محاسبه هوشمند تاریخ شمسی:** محاسبه تاریخ فیلتر از یک ماه قبل‌تر (برای مثال در مهر ماه، فیلتر از ۱ شهریور تنظیم می‌شود).
3. **پیمایش خودکار ۴ نوع گزارش:**
   - خروجی وارداتی (`Rep_RCV_KV.aspx`)
   - خروجی داخلی (`Rep_RCV_KD.aspx`)
   - خروجی صادراتی (`Rep_RCV_KS.aspx`)
   - درون استانی (`Rep_RCV_KO.aspx`)
4. **تشخیص هوشمند وضعیت رکوردها:**
   - صرف‌نظر کردن از رکوردهای تخلیه‌شده.
   - جداسازی رکوردهای با وضعیت **«عدم وصول»** (این رکوردها ثبت تخلیه نمی‌شوند، اما در گزارش نهایی لحاظ می‌گردند).
   - استخراج رکوردهای در انتظار تخلیه همراه با تاریخ صدور و کد رهگیری.
5. **فرآیند ثبت خودکار تخلیه (`Rep_Rcv_takh.aspx`):**
   - جستجوی هر کد رهگیری در باکس `#idcode`.
   - کلیک روی دکمه «تایید تخلیه».
   - درج تاریخ تخلیه به صورت خودکار برای **یک روز بعد از تاریخ صدور**.
   - کلیک روی دکمه «دریافت مستقیم اطلاعات از باسکول» و انتظار برای بارگذاری اطلاعات وزنی.
   - ثبت نهایی با کلیک روی «تایید و ارسال».
6. **خروجی ساختاریافته JSON:**
   - نمایش گزارش کامل تسک هر کاربر در کنسول.
   - ذخیره فایل مجزا برای هر کاربر در `results/report_<username>.json`.
   - ذخیره فایل گزارش تجمیعی در `results/summary_latest.json`.

## 🛠 پیش‌نیازها و نصب

۱. نصب بودن **Node.js** (نسخه ۱۸ یا بالاتر).  
۲. نصب پکیج‌های پروژه:

```bash
npm install
```

اگر اولین بار است که Playwright را روی سیستم اجرا می‌کنید:
```bash
npx playwright install chromium
```

## 🚀 نحوه اجرا

اسکریپت را با دستور زیر در ترمینال اجرا کنید:

```bash
node login.js
```

### مراحل اجرای اسکریپت:
1. مرورگر برای کاربر اول باز می‌شود و نام کاربری و رمز وارد می‌شوند.
2. تصویر کد امنیتی (CAPTCHA) در مرورگر ظاهر شده و ترمینال از شما می‌خواهد کد را وارد کنید:
   ```text
   Enter CAPTCHA for "جعفر شفیعی" (PO42416):
   ```
3. کد را در ترمینال تایپ کرده و **Enter** بزنید.
4. سامانه لاگین شده و به ترتیب گزارش‌های ۴ گانه را با تاریخ محاسبه‌شده فیلتر و جستجو می‌کند.
5. رکوردهای تخلیه‌نشده پیدا شده و به صفحه تایید تخلیه ارسال می‌شوند.
6. تاریخ تخلیه (فردا روز ایجاد)، دریافت اطلاعات باسکول و تایید نهایی زده می‌شود.
7. گزارش نهایی کاربر در قالب JSON در ترمینال چاپ شده و در پوشه `results/` ذخیره می‌شود.
8. سشن کاربر بسته شده و اسکریپت به صورت خودکار سراغ کاربر بعدی می‌رود.

## 📁 ساختار فایل‌های پروژه

```text
ivo-automation/
├── login.js            # فایل اصلی اجرای اتوماسیون
├── users.json          # لیست نام‌کاربری و رمز کاربران
├── README.md           # راهنمای جامع پروژه
├── package.json        # تنظیمات و وابستگی‌های پکیج‌ها
└── results/            # پوشه خروجی گزارش‌های ذخیره‌شده (خودکار ساخته می‌شود)
    ├── report_*.json   # گزارش JSON اختصاصی هر کاربر
    └── summary_latest.json # گزارش تجمیعی تمام کاربران
```
