# سامانه اتوماسیون جامع دامپزشکی (IVO Automation)

این پروژه یک سیستم اتوماسیون جامع مبتنی بر **Playwright** و **Node.js** همراه با **داشبورد تحت وب مینیمال (طراحی Acura)** است که برای تعامل با درگاه خدمات الکترونیک سازمان دامپزشکی کشور (`https://e.ivo.ir`) توسعه یافته است.

---

## 🌟 قابلیت‌های اصلی سامانه

### ۱. صدور خودکار پروانه حمل بهداشتی طیور به کشتارگاه
- ورود خودکار به کارتابل هر دامدار/مرغدار و هدایت به مسیر: `درون استانی > برون شهرستانی > طیور`.
- بررسی دسته‌ای کدهای رهگیری خودرو (از لیست پیش‌فرض یا سفارشی).
- کلیک روی دکمه «حمل به کشتارگاه» به محض یافتن کد معتبر.
- تکمیل خودکار فرم مشخصات محموله:
  - تنظیم نوع کالا (`گوشت مرغ`) و سن گله (`۴۵ روز`).
  - انتخاب خودکار نژاد ثبت‌شده برای مرغدار (`راس`, `کاب`, `آرین` و...).
  - درج کد مجوز جوجه‌ریزی مبدا.
  - درج شناسه یکتای واحد جهاد کشاورزی کشتارگاه مقصد و کلیک روی دکمه «فراخوانی واحد».
  - انتخاب واحد از لیست بازشونده و درج تعداد قطعه (پیش‌فرض ۲۰۰۰).
- صفحه تایید نهایی مجوز (`a2_4_2_tyr_mog_cp.aspx`):
  - درج نام مالک مرغداری.
  - انتخاب جنسیت: `هر دو`.
  - انتخاب به منظور: `(کشتار)`.
  - تنظیم اعتبار مجوز: `۳ روز`.
  - درج خودکار قالب استاندارد ملاحظات شامل کد اپیدمیولوژیک و کد رهگیری.
  - ثبت نهایی و تایید پروانه حمل.

### ۲. استعلام کارتابل‌ها و ثبت خودکار تایید تخلیه گواهی‌ها
- قابلیت اجرای **دسته‌ای برای تمام مرغداران** (پیش‌فرض) یا انتخاب یک مرغدار مشخص.
- محاسبه هوشمند تاریخ فیلتر از یک ماه گذشته (مثلاً در مهر ماه، فیلتر از ۱ شهریور آغاز می‌شود).
- پیمایش خودکار ۴ نوع گزارش در کارتابل:
  1. خروجی وارداتی (`Rep_RCV_KV.aspx`)
  2. خروجی داخلی (`Rep_RCV_KD.aspx`)
  3. خروجی صادراتی (`Rep_RCV_KS.aspx`)
  4. درون استانی (`Rep_RCV_KO.aspx`)
- تفکیک خودکار گواهی‌ها: صرف‌نظر از موارد تخلیه‌شده و دسته‌بندی موارد «عدم وصول».
- هدایت به صفحه ثبت تایید تخلیه (`Rep_Rcv_takh.aspx`):
  - جستجوی کد رهگیری.
  - محاسبه و درج تاریخ تخلیه برای **۱ روز پس از صدور**.
  - فراخوانی اطلاعات باسکول («دریافت مستقیم اطلاعات از باسکول»).
  - ثبت نهایی تایید تخلیه.
- ذخیره‌سازی تاریخ‌دار گزارش‌ها در قالب JSON بدون رونویسی موارد قبلی.

## 💻 راهنمای نصب و راه‌اندازی (روی هر سیستم)

این سامانه روی تمامی سیستم‌عامل‌های **ویندوز (Windows)**، **مک (macOS)** و **لینوکس (Linux/Ubuntu)** قابل اجرا است.

### پیش‌نیازها:
- نصب بودن **Node.js** نسخه ۱۸ یا بالاتر ([دانلود از وب‌سایت رسمی Node.js](https://nodejs.org/)).

---

### گام‌های راه‌اندازی:

#### ۱. دریافت پروژه و باز کردن ترمینال:
پوشه پروژه را در سیستم خود قرار دهید و وارد پوشه پروژه شوید:
```bash
cd ivo-automation
```

#### ۲. نصب وابستگی‌های پروژه (Dependencies):
دستور زیر را در ترمینال یا Command Prompt اجرا کنید:
```bash
npm install
```

#### ۳. نصب مرورگر کرومیوم برای Playwright:
برای اینکه اسکریپت بتواند مرورگر را باز و کنترل کند:
```bash
npx playwright install chromium
```

> **نکته برای کاربران لینوکس/سرور ابری:**  
> اگر روی لینوکس اوبونتو یا دبیان کار می‌کنید، کتابخانه‌های سیستمی مرورگر را نیز با این دستور نصب کنید:
> ```bash
> npx playwright install-deps chromium
> ```

## 🚀 نحوه اجرا

### روش اول: اجرای پنل تحت وب (پیشنهادی)
برای اجرای سرور و دسترسی به رابط کاربری کامل:
```bash
npm start
```
سپس مرورگر خود را باز کرده و به آدرس زیر بروید:
👉 **[http://localhost:3000](http://localhost:3000)**

#### کار با پنل وب:
1. **تب «صدور پروانه حمل طیور»:**
   - انتخاب دامدار مورد نظر.
   - انتخاب کشتارگاه مقصد و تعداد قطعه.
   - کلیک روی **«شروع صدور مجوز»**.
   - در صورت نیاز به کپچا، تصویر امنیتی در پنجره پاپ‌آپ ظاهر می‌شود؛ کد را وارد کرده و Enter بزنید.
   - فرآیند بررسی ۵۰+ کد رهگیری و صدور مجوز به صورت زنده در جدول و لاگ‌ها نمایش داده می‌شود.

2. **تب «استعلام و تایید تخلیه گواهی‌ها»:**
   - به‌طور پیش‌فرض گزینه **«⚡ همه کاربران (بررسی دسته‌ای تمام مرغداران)»** انتخاب شده است (امکان انتخاب تک‌کاربره نیز وجود دارد).
   - کلیک روی **«شروع استعلام و تایید تخلیه خودکار»**.
   - سیستم تک‌تک وارد اکانت‌ها شده، گواهی‌ها را بررسی و تایید تخلیه را ثبت می‌کند.
   - نتایج زنده در کارت‌های آمار و جدول گزارش قرار می‌گیرد.
   - از بخش «مشاهده گزارش‌های پیشین»، می‌توانید هر یک از گزارش‌های تاریخ‌دار گذشته را فورا مشاهده کنید.

---

### روش دوم: اجرای متنی در ترمینال (CLI)
اگر قصد دارید فرآیند استعلام و تایید تخلیه را بدون وب و مستقیماً در کنسول اجرا کنید:
```bash
npm run cli
# یا
node login.js
```
در این حالت کپچا مستقیماً در خط فرمان پرسیده می‌شود.

## 📊 ساختار خروجی و گزارش‌ها (`results/`)

کلیه خروجی‌ها در پوشه `results/` به همراه **تاریخ و ساعت دقیق (Timestamp)** ذخیره می‌شوند تا گزارش‌های قبلی حفظ گردند:

- **گزارش‌های تاریخ‌دار هر کاربر:**  
  `results/report_PO42416_2026-10-02T18-09-30-736Z.json`  
- **آخرین وضعیت کاربر:**  
  `results/report_PO42416.json`
- **گزارش تجمیعی کل تاریخ‌دار:**  
  `results/summary_2026-10-02T18-10-00-000Z.json`
- **آخرین گزارش تجمیعی کل:**  
  `results/summary_latest.json`

```text
├── results/                # آرشیو گزارش‌های تفکیکی و تجمیعی تاریخ‌دار
├── package.json            # اسکریپت‌ها و وابستگی‌های پروژه
└── README.md               # راهنمای کامل راه‌اندازی و استفاده
```

## ❓ پرسش‌های متداول و عیب‌یابی

1. **خطای عدم اجرای مرورگر (`Executable doesn't exist`):**  
   با دستور `npx playwright install chromium` مطمئن شوید که مرورگر دانلود شده است.

2. **پرت شدن به صفحه لاگین حین کار:**  
   در صورت کندی سامانه دامپزشکی یا نامعتبر شدن سشن، سیستم خودکار پیام هشدار داده و منتظر درخواست بعدی می‌ماند.

3. **حالت بدون تصویر (Headless):**  
   در هر دو تب رابط کاربری، گزینه «نمایش مرورگر» تعبیه شده است. اگر تیک آن را بردارید، مرورگر در پس‌زمینه (Headless) اجرا می‌شود.
